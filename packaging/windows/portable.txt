PDFKraft portable mode

While this file sits next to pdfkraft.exe, PDFKraft keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the PDFKraftData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move PDFKraft with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\PDFKraft and
%LOCALAPPDATA%\PDFKraft) instead. If PDFKraftData can't be written (for example on a read-only
drive), PDFKraft says so and uses the per-user folders instead.
